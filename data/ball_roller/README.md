# 🔥 Ball Roller - 3D Physics Animation

Beautiful 3D ball rolling simulations with realistic physics and neon aesthetics.

## Features

✅ Procedurally generated tracks (platforms, ramps, tubes, spirals)
✅ Real physics simulation (gravity, collision, rolling)
✅ Neon aesthetic with dynamic lighting
✅ Smooth camera tracking
✅ Natural sound effects (rolling, impact, collision)
✅ YouTube Shorts optimized (1080x1920)
✅ Daily automation

## Requirements

- Blender (free) - https://www.blender.org
- Python 3.8+
- FFmpeg
- scipy, numpy

## Installation

1. Install Blender
2. Install dependencies: `pip install scipy numpy`
3. Install FFmpeg
4. Clone scripts to your project
5. Run: `python3 ball_roller_automation.py`

## Output

- 15-second videos
- 1080x1920 resolution
- MP4 format
- Ready for YouTube Shorts

## How it works

Each day, the system:
1. Generates random scene config
2. Creates 3D track in Blender
3. Simulates physics
4. Renders video
5. Adds sound effects
6. Ready to upload

Fully automated after setup!
