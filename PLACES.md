# 🌍 PLACES

Beautiful locations from around the world.

## Project Details

- **Channel Name:** Places
- **Content:** Beautiful locations + natural sound
- **Frequency:** Daily
- **Format:** YouTube Shorts (1080x1920)

## Locations

- Mount Everest, Nepal
- Victoria Falls, Zimbabwe
- Northern Lights, Iceland
- Great Barrier Reef, Australia
- Sahara Desert, Morocco
- Banff National Park, Canada
- Patagonia, Argentina

## System

Automated daily generation:
1. Select random location
2. Fetch video from Pexels/Pixabay
3. Add location text overlay
4. Render final video
5. Upload to YouTube Shorts

All videos have **natural sound only** - no music, no narration.
